# MyOs

**MyOs** adalah aplikasi Dynamic Island / Notch virtual bergaya macOS untuk Windows 10/11. Repositori ini khusus menyediakan file aplikasi siap pakai (`MyOs.exe`) di bagian **Releases** beserta informasi pembaruan (changelog) di setiap versinya.

## ✨ Fitur Utama
- **Pill Idle & Animasi Pegas 120Hz+**: Tampilan halus dengan fisika pegas (spring) yang menyesuaikan refresh rate layar.
- **Beranda**: Jam digital, tanggal, prakiraan cuaca otomatis, dan indikator daya/baterai.
- **Musik & Lirik**: Kontrol media terintegrasi dengan Windows Media Control dan lirik tersinkron otomatis.
- **Notifikasi Terpadu**: Menampilkan toast notifikasi Windows langsung di dalam notch lengkap dengan tombol balas cepat.
- **Tray File Sementara**: Seret dan lepas (drag & drop) file ke dalam notch untuk disimpan sementara dan dipindahkan dengan cepat.
- **Monitor Sistem**: Pantau penggunaan CPU, RAM, kecepatan jaringan, kapasitas disk, dan baterai secara real-time.
- **Timer, Stopwatch & Clipboard**: Pengatur waktu cepat dan penyimpanan riwayat teks clipboard secara manual.
- **Kustomisasi Tema**: Ubah seluruh warna elemen dengan mode solid maupun gradasi langsung dari menu Pengaturan di dalam notch.

# MyOs

## ✨ Fitur Utama
- **Mode Notch & Dynamic Island**: Pilih gaya notch menempel di tepi atas layar atau kapsul mengambang ala iPhone Dynamic Island dengan animasi pegas 120Hz+.
- **Beranda**: Jam digital, tanggal, prakiraan cuaca otomatis berdasarkan lokasi Windows, dan indikator daya/baterai.
- **Musik & Lirik**: Kontrol media terintegrasi dengan Windows Media Control, equalizer warna tema, dan lirik tersinkron otomatis.
- **Notifikasi Terpadu**: Menampilkan toast notifikasi Windows beserta avatar pengirim, tombol Sudah Dibaca, Buka, dan balas cepat.
- **Myku AI**: Asisten AI multi-penyedia (Gemini, Claude, OpenAI, OpenRouter, Groq, DeepSeek, Grok, Mistral) dengan deteksi otomatis dari API Key.
- **Tray File Sementara**: Seret dan lepas (drag & drop) file ke dalam notch untuk disimpan sementara dan dipindahkan dengan cepat.
- **Monitor Sistem**: Pantau penggunaan CPU, RAM, kecepatan jaringan, kapasitas disk, dan baterai secara real-time.
- **Timer, Stopwatch & Clipboard**: Pengatur waktu cepat dan integrasi riwayat Clipboard Windows (`Win + V`).
- **Kustomisasi Tema & Bahasa**: Ubah seluruh warna elemen (solid maupun gradasi) dan pilih 6 bahasa langsung dari Pengaturan di dalam notch.
